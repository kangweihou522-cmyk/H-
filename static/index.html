① 样本与输入

在 Ubuntu 中填写绝对路径。Windows D: 盘对应 /mnt/d/；建议把 FASTQ 和运行目录放在 WSL Linux 文件系统，避免跨盘 I/O 开销。

batch 可省略；单端去掉 fastq2 列。计数模式仅需 sample、group 和可选 batch；Salmon 模式使用 quant 列指向 quant.sf。本版一次对比两个分组，每组至少 2 个生物学重复，推荐 ≥3。

仅用于程序验证，不代表真实生物学结果。

② 差异分析与通路

Salmon 使用 selective alignment、序列/GC 偏差校正；tximport 把转录本汇总到基因，DESeq2 使用长度偏移量。GO 使用小鼠 org.Mm.eg.db；GSEA 按 DESeq2 Wald 统计量排序，使用确定性基因集合排列。KEGG/GMT 使用实际检测到且能映射的基因作为背景。

本地部署
在 Ubuntu / WSL2 中执行 bash install.sh，完成后执行 bash launch.sh。Windows 也可双击 启动工作站.bat（默认 Ubuntu-24.04）。Docker Desktop 需开启该 WSL 发行版集成；原生 Ubuntu 可使用 Docker Engine。
32GB 机器默认使用 4 线程和每个容器最多 24GB，任务按顺序执行。Docker 镜像和 Python 依赖准备完毕后可离线分析；FASTQ 模式仍需你提供匹配版本的参考转录本与 tx2gene。使用 Ensembl 小鼠基因 ID 可获得 GO 注释；KEGG 可使用你获准使用的 GMT，或运行 scripts/fetch_kegg.py 从 KEGG REST 构建。
安装、参考数据准备、链特异性和验证限制详见仓库 README.md。任务日志、计数矩阵、DESeq2 RDS、R 版本记录及绘图结果都保存在 runs/任务ID/。
