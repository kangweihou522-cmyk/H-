样本与实验设计

先检查样本、参考版本与比较组合，再启动分析。支持多个分组和批次/配对对象等协变量。

1. 项目与输入

Windows 路径会转换为 /mnt/盘符/。为了更好的读写性能，建议把 FASTQ 放在 WSL 的 Linux 文件系统。TPM/FPKM 仅可用于表达展示，不能输入 DESeq2。

样本清单与分组

默认保留所有样本。排除需有实验/质量依据；排除记录会保留在参数与报告中，工作站不会自动删除异常样本。

2. 比较组合与统计设计

比较名（英文/数字）对照组处理组

所有样本共同拟合 DESeq2，比较方向为“处理组 / 对照组”。协变量必须来自样本表；如分组与批次混杂，或没有残差自由度，启动前会拒绝。配对实验可使用 subject 协变量，但每组仍需多个独立对象。

3. FASTQ 预处理

保存 fastp JSON/HTML、过滤前后 reads、Q20/Q30、GC、接头与碱基质量曲线；Salmon 保存映射率、文库类型和量化结果；另生成 MultiQC 汇总。这里的 Salmon 映射率不是基因组 unique mapping，也不能推导内含子/外显子分布。

4. 注释、通路与数据挖掘

GO/GMT 分别输出全部、上调和下调基因的富集。GSEA 不按 DEG 阈值预筛，使用 Wald stat 和 fgsea multilevel，输出 NES、BH padj、log2err、leading-edge 基因和富集曲线。通路活性使用各样本 VST，组间检验采用相同协变量。

从通路定位到基因，再回到样本

通路活性与关键基因

ssGSEA 提供每个样本的通路活性；limma 组间比较调整与 DESeq2 相同的协变量。结合 GSEA leading-edge、LFC 和重复表达筛选候选基因。

基因级探索

模块、表型和候选 hub 基因

共表达网络与表型关联

WGCNA signed 网络使用最高变异基因，输出软阈值诊断、模块、eigengene、kME、模块–表型关联和网络边表。关联是探索性统计，不能当作因果证据。

使用前提与解读

至少15个独立样本，推荐20个以上；配对对象不能重复计作独立样本。软阈值6只是可调整的初始值，应结合输出的 scale-free 拟合和连接度诊断选择。模块–表型相关目前为未调整协变量的 Pearson 关联，并对表格内检验作 BH 校正；重复测量或批次混杂需要进一步建模。

当前6样本项目可以做候选基因和通路探索，但 WGCNA 会明确跳过。
